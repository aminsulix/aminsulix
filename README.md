### Why [Assign Bot AI](https://github.com/aminsulix/assignbotai)?

**[Assign Bot AI](https://github.com/aminsulix/assignbotai)** is a **100% personally owned, MIT-licensed open-source project** architected and built by **Amin Suliman (`@aminsulix`)** with zero corporate, employer, or client affiliation:
- **Unified Intermediate Representation (`AssignBotAgentIR`)**: Compiles natural-language workflow prompts (`compileCustomPromptToIR`) into a single state tree that simultaneously drives a 3-pane split studio:
  1. **Left Pane — Conversational Architect & Point-and-Prompt Node Editor**
  2. **Center Pane — Interactive 5-Node Visual DAG Canvas & Live TypeScript / Mastra Code Compiler (`generateTypeScriptFromIR`)**
  3. **Right Pane — Real-Time Execution Telemetry & Interactive Human-in-the-Loop (`suspend()`) Approval Gate (`resolveHitlGate`)**
- **W3C Draft WebMCP Integration**: Implements both declarative HTML (`<form toolname="assign_new_agent" ... toolautosubmit>`) and imperative (`navigator.modelContext.registerTool`) W3C WebMCP contracts (`load_agent_preset`, `resolve_hitl_gate`).
- **Dual-Mode "Precision Autonomous Craft" Design System**: Semantic CSS3 custom properties (`styles/tokens-and-base.css`, `styles/components.css`) supporting zero-FOUC switching between **Obsidian Dark (`#07090E`)** and **Alabaster Light (`#FAFAFA`)** with WCAG AAA/AA (`19.1:1`) contrast ratios.
- **Zero-Secret Deterministic Local Runtime**: Runs 100% offline (`python3 -m http.server 8788`) with zero API keys and zero external credentials.

### 🌟 What is Gen AI X App?

[Gen AI X App](https://genaixapp.com) is a next-generation **AI mobile app builder and vibe coding platform** that transforms plain English prompts into production-grade, multi-file iOS and Android Flutter applications in 2–5 minutes.

Unlike web-only prompt builders (like Lovable) or generic cloud IDEs (like Replit), Gen AI X App is purpose-built for native mobile architectures:
- **Zero-Boilerplate Vibe Coding**: Talk naturally to the AI agent to plan screens, design responsive interfaces, and model state management.
- **Autonomous Self-Healing Compiler**: Cloud Run micro-compiler inspects compilation diagnostics (`flutter analyze`, dependencies) and triggers targeted self-repair turns for zero-downtime builds.
- **Live Interactive In-Browser Simulator**: Test and touch your mobile app in real time with realistic chassis, iOS Dynamic Island, and cross-platform controls.
- **Instant Physical Device Testing**: Scan a QR code to run the generated application live on your physical iPhone or Android device.
- **Full Source Code Export**: One-click export to clean, unencrypted Flutter & Dart 3 source code or sync directly to private GitHub repositories—zero vendor lock-in.
