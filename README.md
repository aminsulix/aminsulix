### 🌟 What is Gen AI X App?

[Gen AI X App](https://genaixapp.com) is a next-generation **AI mobile app builder and vibe coding platform** that transforms plain English prompts into production-grade, multi-file iOS and Android Flutter applications in 2–5 minutes.

Unlike web-only prompt builders (like Lovable) or generic cloud IDEs (like Replit), Gen AI X App is purpose-built for native mobile architectures:
- **Zero-Boilerplate Vibe Coding**: Talk naturally to the AI agent to plan screens, design responsive interfaces, and model state management.
- **Autonomous Self-Healing Compiler**: Cloud Run micro-compiler inspects compilation diagnostics (`flutter analyze`, dependencies) and triggers targeted self-repair turns for zero-downtime builds.
- **Live Interactive In-Browser Simulator**: Test and touch your mobile app in real time with realistic chassis, iOS Dynamic Island, and cross-platform controls.
- **Instant Physical Device Testing**: Scan a QR code to run the generated application live on your physical iPhone or Android device.
- **Full Source Code Export**: One-click export to clean, unencrypted Flutter & Dart 3 source code or sync directly to private GitHub repositories—zero vendor lock-in.

### ⚡ Core Architecture & Engineering Highlights

- 🤖 **Autonomous Multi-Turn Agent**: Employs structured tool calls to plan, generate, and maintain multi-file Flutter code trees.
- 📱 **Interactive In-Browser Simulator**: Test, touch, scroll, and interact with the compiled mobile app in real-time with realistic iPhone chassis and Dynamic Island.
- 📲 **Instant QR Code On-Device Testing**: Scan a QR code to run the generated native mobile app directly on your physical iPhone or Android device.
- 🔁 **Self-Healing Compiler Loop**: Google Cloud Run micro-compiler inspects compilation diagnostics and triggers targeted self-repair turns.
- 🔄 **1-Click GitHub Synchronization**: Seamlessly sync your generated codebase directly to private or public GitHub repositories for complete code ownership.
- 💳 **Production Billing & Rollover Protection**: Stripe Billing integration supporting weekly subscription tiers and non-expiring credit packs with 12-month rollover protection.
